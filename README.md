# 🏰 Raja Shivaji - Movie Website

A responsive and visually attractive movie website dedicated to the historical movie **Raja Shivaji**.  
The website provides information about the movie, cast & crew, songs, and a fan club section.

## 🌐 Live Website

🔗 https://gaurimahadkar.github.io/Raja-Shivaji/

## 📌 About the Project

**Raja Shivaji** is a front-end movie website created using HTML and CSS.  
The website presents movie-related information in a clean, modern, and responsive design.

Users can explore:

- 🎬 Movie information
- 👥 Cast & Crew
- 🎵 Movie Songs
- ❤️ Raja Shivaji Fan Club
- 🎫 Book Tickets section
- 📱 Social media links
- 💳 Payment options

## ✨ Features

### 🎬 Movie Information
- Movie overview
- Release date
- Producer information
- Book Tickets button

### 👥 Cast & Crew
The website displays major cast members with their images and character names.

### 🎵 Movie Songs
- Song titles
- Built-in audio players
- Download Song buttons

### ❤️ Fan Club
Users can join the Raja Shivaji Fan Club by submitting:
- Full Name
- Email
- Message

### 📱 Responsive Design
The website is designed to provide a smooth experience across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- HTML5 Audio
- GitHub Pages
